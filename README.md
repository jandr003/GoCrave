# GoCrave

**GoCrave** is an Android food ordering application built with Java and XML. It provides users with a convenient way to browse food items, view product details, manage their cart, and place orders.

## ✨ Features

* **Browse Food Menu**
* **Food Categories**
* **Product Details**
* **Shopping Cart**
* **Checkout**
* **Order History**
* **User Profile**

## 🛠️ Tech Stack

* **Java**
* **XML**
* **Android Studio**

## 📋 Requirements

* **Android 10 (API 29) or later**
* **Internet Connection**

## 📱 Supported Devices

* **Android Smartphones**

## 📌 Project Status

**Current Status: 🚧 In Development**

GoCrave is currently under development, with ongoing improvements to the user interface, design, and application features.
