# GoCrave

GoCrave is an Android food ordering application built with Java and XML. It allows users to browse food items, add them to their cart, and place orders through a simple and user-friendly interface.

## Features

- Browse Food Menu
- Food Categories
- Product Details
- Shopping Cart
- Checkout
- Order History
- User Profile

## Tech Stack

- Java
- XML
- Android Studio

## Requirements

- Android 10 (API 29) 
- Internet Connection
