# GoCrave

**GoCrave** is an Android food ordering application designed to provide users with a simple and convenient way to browse food items, manage their cart, place orders, and track order progress.

## ✨ Features

* **Food Menu**
* **Food Categories**
* **Product Details**
* **Shopping Cart**
* **Checkout**
* **Order Tracking**
* **Order History**
* **User Profile**

## 🛠️ Tech Stack

| Technology         | Purpose                                |
| ------------------ | -------------------------------------- |
| **Flutter**        | Android mobile application development |
| **Dart**           | Application development                |
| **Node.js**        | Backend runtime                        |
| **Express.js**     | REST API development                   |
| **PostgreSQL**     | Database management                    |
| **Android Studio** | Android development and testing        |

## 📋 Requirements

Before running the application, make sure the following are installed:

* **Android Studio**
* **Android SDK**
* **Flutter SDK**
* **Dart SDK**
* **Node.js**
* **PostgreSQL**
* **Android 10 (API 29) or later**

An internet connection is required for features that communicate with the backend API.

## 📱 Supported Platform

* **Android Smartphones**

## 📌 Project Status

**Current Status: 🚧 Under Development**
